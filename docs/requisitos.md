# Introducción

Este documento reúne los requisitos funcionales y no funcionales que definirán el comportamiento y las características de la plataforma Raíces Alzate.

---

# Requisitos Funcionales

## Módulo de Inicio

- Mostrar la página principal del proyecto.
- Presentar información institucional.
- Mostrar acceso al inicio de sesión.
- Mostrar acceso al registro de usuarios.

---

## Módulo de Autenticación

- Iniciar sesión.
- Cerrar sesión.
- Recuperar contraseña.
- Cambiar contraseña.
- Mantener la sesión iniciada.

---

## Módulo de Usuarios

- Registrar usuarios.
- Editar perfil.
- Cambiar fotografía.
- Actualizar información personal.

---

## Módulo de Egresados

- Registrar egresados.
- Consultar información.
- Buscar egresados.
- Filtrar resultados.
- Visualizar perfiles.

---

## Módulo de Proyectos

- Publicar proyectos.
- Editar proyectos.
- Eliminar proyectos.
- Consultar proyectos publicados.

---

## Módulo Administrativo

- Gestionar usuarios.
- Gestionar egresados.
- Gestionar proyectos.
- Administrar permisos.
- Visualizar estadísticas.

---
